ASSETS FOLDER
=============

Place the following files here:

  myhq_logo.png
  └── The official myHQ logo (white on blue background, or transparent PNG).
      Recommended size: 200×80px or 120×120px (square version).
      To use it in the template, replace the SVG logo block in newsletter.html
      with: <img src="assets/myhq_logo.png" alt="myHQ" height="40">

The current template uses an inline SVG approximation of the myHQ logo
that matches the brand blue (#2B2FE6). This works without any file needed.
